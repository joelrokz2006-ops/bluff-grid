# BLUFF GRID — Read the Tell. Beat the House.

A noir casino minesweeper game written in React + Vite with synthesized Web Audio sound effects, 3D card flips, particle systems, dynamic multiplier math, and Sal "The Snake" Malone's animated tell system.

## Getting Started

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## Features
- **True Combinatorial Odds**: Dynamic multiplier system with transparent odds calculations.
- **Sal "The Snake" Malone**: Animated dealer with dynamic facial expressions, speech bubble with typewriter dialogue, and visual tells (sweat drops & eye darts).
- **Bluff Mechanic**: Call Sal's bluff when he vouches for a tile to defuse bombs for a 1.6× bonus or risk halving your pot on false calls.
- **Synthesized Web Audio Engine**: Procedural card flips, chips, detonations, and chimes without external audio asset dependencies.
- **Persistent State**: Bankroll, stakes, records, and preferences stored in `localStorage`.
